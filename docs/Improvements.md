# Known Issues and Improvements

## Documentation
- 全体の設計思想やチュートリアルの不足。README.md やサンプルプロジェクトが必要。
- 各クラスの詳細な使用例が少ない。

## Error Handling
- None チェックはあるが、より堅牢なエラーハンドリングが必要。
- デバッグ時のログ出力が不十分。何が起こっているかわかりにくい。

## Feature Maturity
- Animator のアニメーション辞書の使い方が不明瞭で、実用的でない。
- 物理エンジンの不在。重力や当たり判定を毎回手実装する必要がある。
- カメラ機能が追従のみ。ズームや境界設定がない。

## Input Handling
- キーボード入力のみ。ゲームパッドやタッチ入力に対応していない。
- InputStatus がシンプルすぎる。

## Asset Management
- 画像パスがハードコード。アセットの動的ロードやキャッシュがない。
- ビルドプロセスがない。大規模ゲーム開発に向かない。

## Testing
- ユニットテストや統合テストがない。フレームワークの信頼性が低い。

## Performance
- 大量のゲームオブジェクト時の最適化不足。描画の画面外カリングが不十分。
